# AI Assistive Smart Glasses 👓🤖

An assistive smart-glasses project designed to help visually impaired users better understand and navigate their surroundings.

The proposed system combines **computer vision, text recognition, and ultrasonic sensing** to provide information about nearby objects, readable text, and obstacles.

---

## 💡 Project Overview

The system was designed around a wearable platform capable of processing information from the user's surroundings and providing useful feedback.

### Main Functions

- 👁️ **Object Detection** — Identifying objects in the user's environment using computer vision.
- 📝 **Text Recognition** — Detecting and reading visible text.
- 📡 **Obstacle Detection** — Using ultrasonic sensing to detect nearby obstacles.
- 🔊 **User Feedback** — Providing information to the user through an appropriate feedback mechanism.
